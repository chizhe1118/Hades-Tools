# Hades Tools v0.2.6

## Highlights

- Ragebot settings are consolidated into one section: target priority, lock hold, weapon synchronization, perfect bow timing, spread mode, auto aim, auto fire and silent shot.
- Faster target reacquisition and improved projectile accuracy.
- Adamant Rail burst and infinite-ammo upgrades are supported.
- Remove Spread also clears weapon movement halt and post-attack slowdown properties while active.
- Player attributes, active boons and weapon upgrades are editable from Player State.
- Official Simplified Chinese game text is used for 446 catalog entries.
- A single-file Windows package is available alongside the portable directory package.

## Downloads

- `HadesTools-v0.2.6-single.exe`: one-file build; recommended for most users.
- `HadesTools-v0.2.6-win64.zip`: extract the complete directory before running.
- `HadesTools-v0.2.6-source.zip`: complete offline source package.
- `SHA256SUMS.txt`: checksums for release verification.

## Compatibility

Verified against Steam Hades x64 build ID `10929685`, with `EngineWin64s.dll` SHA256 `4165a69c9ed8f48d9c839609011da55c12bbc877eb9b0550c4b099bd0524befd`.

This build is unsigned, so Windows SmartScreen can show an unknown-publisher prompt. The release SHA256 values allow the downloaded files to be checked against the published build.

## Run

Start Hades, load a save, enter gameplay, start Hades Tools and select **连接游戏**. Close the in-game pause menu before issuing commands.
