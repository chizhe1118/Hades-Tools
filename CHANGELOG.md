# Changelog

## 0.2.6 - 2026-10-15

- Reorganized the Functions page so player attributes live under Player State and combat toggles remain prominent.
- Added Ragebot target priority, lock hold, fast switching, weapon synchronization and perfect bow release timing.
- Added Off, Seed Check and Remove Spread modes with editable spread values.
- Improved silent projectile targeting, target reacquisition and multi-projectile weapon handling.
- Supported infinite-ammo and burst-fire Adamant Rail upgrades.
- Restored weapon properties when Ragebot is disabled or the active weapon changes.
- Added attack movement cleanup for the Adamant Rail and Heart-Seeking Bow.
- Added a self-extracting single-file Windows package.
